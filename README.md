# แพกุ้งโชคศิริวัฒน์ฟาร์ม — ระบบจัดการสต็อก (v3)

React + TypeScript + Tailwind + Supabase + lucide-react

## หน้าหลัก — Tile 8 ช่อง (จับคู่กัน)

| คู่ที่ 1 | คู่ที่ 2 | คู่ที่ 3 | คู่ที่ 4 |
|---|---|---|---|
| สินค้า | ประวัติซื้อขาย | ซื้อ | ขาย |
| รายรับ | รายจ่าย | เพิ่มสินค้า | เพิ่มผู้ซื้อ/ผู้ขาย |

- **สินค้า** — ดูสต็อกแยกหมวด ปรับยอด (Adjust) ได้ตรงนี้เลย (เฉพาะ Admin)
- **ประวัติซื้อขาย** — เลือกซื้อ/ขาย + คู่ค้า + วันที่ย้อนหลัง ดูรายการทั้งหมด
- **ซื้อ** — เลือก Supplier + เลขที่บิล เห็นเฉพาะสินค้าที่ผูกไว้กับ Supplier รายนั้น มีลิงก์ไปหน้ารายจ่ายของ Supplier นั้นทันที
- **ขาย** — เลือก Customer แล้วกด "เพิ่มรายการสินค้า" ทีละแถว มีลิงก์ไปหน้ารายรับของลูกค้านั้น
- **รายรับ** — รายชื่อ Customer ทั้งหมดพร้อมยอดคงค้าง (แสดงแม้ 0 บาท) คลิกเข้าไปดูบัญชีแบบเลือกปี/เดือน (Dropdown + ลูกศรเลื่อน) ดูรายละเอียดสินค้าต่อรายการซื้อได้ และบันทึกการจ่ายเงิน (จำนวนใดก็ได้ ไม่ผูกกับบิล)
- **รายจ่าย** — ยอดค้างจ่ายต่อ Supplier คลิกดู List บิล (เลขที่/วันที่/ยอดรวม) กด "ชำระเงิน" กรอกยอดจริงตามใบแจ้งหนี้ ระบบคำนวณส่วนลด (บาท+%) ให้ก่อน Confirm
- **เพิ่มสินค้า / เพิ่มผู้ซื้อ-ผู้ขาย** — Master data เหมือนเวอร์ชันก่อนหน้า (แก้ไข/ลบได้)

ไม่มีหน้า "ผู้ใช้งาน" เพราะใช้งานคนเดียวเป็น Admin

## ถ้ามี Supabase Project เดิม (จากเวอร์ชันก่อนหน้า)

**อย่ารัน `schema.sql` ซ้ำ** ให้รัน **`supabase/migration_v3.sql`** แทนใน SQL Editor
(เพิ่มคอลัมน์เลขที่บิล/สถานะจ่ายในตาราง transactions และตาราง customer_payments ใหม่)

## ถ้าเริ่มโปรเจกต์ใหม่ตั้งแต่ต้น

รัน `supabase/schema.sql` ทั้งไฟล์ แล้วสร้างผู้ใช้คนแรกที่ Authentication → Users
ตั้งเป็น admin ด้วย:
```sql
update profiles set role = 'admin' where id = '<UUID>';
```

## รันโปรเจกต์

```bash
cp .env.example .env   # ใส่ค่า Supabase URL/anon key
npm install
npm run dev
```

## Deploy

`npm run build` แล้วนำโฟลเดอร์ `dist/` ขึ้น Vercel/Netlify (ตั้ง Environment
Variables สองตัวในระบบ deploy ด้วย)
